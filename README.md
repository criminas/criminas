<details>

<details>

## How I build

I pick projects where I can hold the whole stack in my head. Frameworks hide the interesting part, so I reach for the standard library first and add a dependency only when writing it myself would waste a week.

My repos hold finished tools, half-finished experiments, and whatever I broke last weekend. Dig around.
